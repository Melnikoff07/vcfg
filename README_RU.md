# VCFG (по-русски)

**Актуальный релиз: [v2.36](https://github.com/Melnikoff07/vcfg/releases/tag/v2.36) (1 ноября 2026).** Перед обновлением прочитайте примечания именно к устанавливаемой версии.

*Независимый любительский проект, не связан с Sony Interactive Entertainment и издателями игр. «PS4» упомянут только
как обозначение платформы. Игры обозначены по Title ID, кода и ресурсов игр в репозитории нет.*

VCFG (vibe coded frame generator): генерация промежуточных кадров для игр на консолях PS4 с GoldHEN, в виде плагина GoldHEN. Плагин перехватывает вывод кадров игры, на GPU строит
поле движения между предыдущим и текущим кадром, рисует промежуточный кадр и показывает его перед настоящим.
Игра 30 fps выглядит как 60.

**Статус: эксперимент.** Совместимость зависит от CUSA ID, версии игры, модели консоли и режима вывода.
Смотрите [совместимость и известные проблемы](docs/COMPATIBILITY.md).

## Что нового в v2.36

- **Quality** сохраняет прежний режим качества. **Fast** сокращает очередь показа и использует пейсинг по таймеру для снижения задержки. **Sharp** сильнее повышает резкость реального кадра перед генерацией.
- Меньше мерцания повторяющихся текстур и тонких объектов, исправления контуров и краёв экрана; поддержка 3200×1800 и не-16:9 в проходе warp.
- Исправления звука, памяти и падений для ряда CUSA; меню показывает фактическое состояние опций (ACTIVE / READY / INERT / LIMITED).
- Сборка для Linux/macOS через [Docker](tools/docker-build/README.md).

Установите **VCFG_v2.36.pkg** из [релиза](https://github.com/Melnikoff07/vcfg/releases/tag/v2.36).
Старые `config-<TITLE>.ini` работают; данные адаптации `adapt-*` сбрасываются при первом запуске.
Оставьте активным один плагин VCFG. Для **CUSA10237** выключите VCFG: этот CUSA пока не поддерживается.
Полный список изменений и ограничений — в примечаниях к релизу.

## Как это устроено

1. **Проверка.** Плагин изучает буферы игры, формат пикселей, команды GPU и свободную DirectMemory перед включением генерации.
2. **Генерация.** Поиск движения и warp на GPU строят промежуточное изображение из соседних кадров. Работа с памятью и показом зависит от движка и профиля CUSA.
3. **Показ.** Quality, Fast и Sharp отличаются пейсингом или резкостью. Если проверки безопасности не проходят, кадр показывается без генерации.

## Установка

1. Скачайте `VCFG_vX.pkg` из [Releases](https://github.com/Melnikoff07/vcfg/releases) и установите через GoldHEN
   Package Installer (например из `/data/pkg`).
2. Включите **GoldHEN → Settings → Plugins**. Запустите **VCFG** с главного экрана. При старте приложение само копирует плагины в `/data/GoldHEN/plugins/`,
   делает бэкап `plugins.ini` и прописывает проверенные игры (ваши другие плагины остаются).
3. Выберите игру: крестик включает FG, треугольник открывает настройки, квадрат запускает игру. Остальные
   игры показаны как EXPERIMENTAL и выключены, пока вы их не включите.
4. Запустите игру, подождите ~20 секунд, удерживайте **L3+R3 3 секунды**, откроется меню.

**Отключение и очистка:** во вкладке **04 PLUGIN** квадрат (**TURN OFF**) и двойное R2 (**WIPE ALL**) удаляют
файлы плагина VCFG, его записи и резервные копии `plugins.ini`, настройки, адаптацию и профили. Логи в
`/data/bb_probe/` и чужие плагины сохраняются. Пока VCFG выключен, приложение показывает красное сообщение
**VCFG IS TURNED OFF**. Для повторного включения нажмите крестик (**INSTALL**) во вкладке **04 PLUGIN** и
полностью перезапустите игру. Если нужен единый файл для отправки, сохраните отчёт до очистки.

## Если что-то сломалось

В приложении: вкладка **04 PLUGIN** → треугольник (**debug log on**) → запустите игру и повторите проблему →
снова в приложении кружок (**save report**). Приложите `vcfg_report.txt` (на флешке или `/data/vcfg_report.txt`
по FTP) к [issue](https://github.com/Melnikoff07/vcfg/issues/new?template=bug_report.md).

## Быстрый старт (для разработчиков)

```powershell
copy config.example.json config.json      # пути к тулчейну и IP консоли
powershell -NoProfile -ExecutionPolicy Bypass -File build.ps1
python -I tools/console.py set CUSA07439 build/vcfg/vcfg.prx
```

Запустите игру заново. Секунд через 20 удерживайте **L3+R3 3 секунды**, откроется меню.
