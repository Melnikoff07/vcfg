# VCFG (по-русски)

*Независимый любительский проект, не связан с Sony Interactive Entertainment и издателями игр. «PS4» упомянут только
как обозначение платформы. Игры обозначены по Title ID, кода и ресурсов игр в репозитории нет.*

VCFG (vibe coded frame generator): генерация промежуточных кадров для игр на консолях PS4 с GoldHEN, в виде плагина GoldHEN. Плагин перехватывает вывод кадров игры, на GPU строит
поле движения между предыдущим и текущим кадром, рисует промежуточный кадр и показывает его перед настоящим.
Игра 30 fps выглядит как 60.

**Статус: эксперимент.** На железе работает CUSA07439 (30 → 60, меню, резкость, overlay). Частично работает
CUSA09171: FG примерно на 40% кадров, мигает HUD. Не работает пока CUSA13801, а также CUSA08519 на этом плагине.
Проверено только на обычной (не Pro) консоли с GoldHEN. Используете на свой риск.

## Как это устроено

1. **Наблюдение.** Первые ~600 кадров плагин только смотрит: буферы игры, формат, свободную память.
2. **Решение.** Плагин занимает ~5 МБ под промежуточный кадр 1280×720 и рабочие данные, на самом верху свободной
   DirectMemory. Каждый кадр он проверяет форму flip, размер буферов команд и состояние compute-регистров. Если
   что-то не сходится, этот кадр показывается без FG.
3. **Генерация.** Команды GPU добавляются к отправке кадра самой игры: пирамиды яркости → поиск движения →
   фильтрация → фаза → warp в 720p → резкость или AA → показ промежуточного кадра, затем настоящего.

## Быстрый старт

```powershell
copy config.example.json config.json      # пути к тулчейну и IP консоли
powershell -NoProfile -ExecutionPolicy Bypass -File build.ps1
python -I tools/console.py set CUSA07439 build/vcfg/vcfg.prx
```

Запустите игру заново. Секунд через 20 удерживайте **L3+R3 3 секунды**, откроется меню.

## Чем помочь

Больше всего сейчас нужны **данные по играм**. Поставьте разведчик в `[default]`, поиграйте 5 минут, затем:

```powershell
python -I tools/console.py logs
python -I tools/analyze.py logs
```

Отчёт из `analyze.py` выложите в Issues. Подробности: [docs/CONTRIBUTING.md](docs/CONTRIBUTING.md), план: [docs/ROADMAP.md](docs/ROADMAP.md).
